# Security Policy

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability, leaked credential, or private transcript. Use GitHub's private security advisory flow for this repository, or contact the maintainer through GitHub to arrange a private report.

Include the affected version, a minimal reproduction, impact, and any suggested mitigation. Please do not include real credentials or private session content in the report.

## Supported versions

Security fixes are applied to the latest released version on the default branch.

## Installation safety

Pi packages execute with the permissions of the user running Pi. Review updates before installing them and do not install this package from an untrusted fork or commit.
